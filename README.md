### Como salvar códigos (Codespace ➔ Repositório)

1. **Verificar onde você está e o que mudou:** 

bash

pwd          # Mostra a pasta atual onde você está trabalhando
ls           # Lista os arquivos e pastas do local
git status   # Mostra os arquivos novos, modificados ou deletados

Use o código com cuidado.
2. **Preparar os arquivos (Stage):** 

bash

git add .               # Adiciona TUDO o que foi modificado
git add minha-pasta/    # Adiciona apenas uma pasta específica

Use o código com cuidado.
3. **Gravar a alteração localmente:** 

bash

git commit -m "Mensagem explicando o que foi feito"

Use o código com cuidado.
4. **Enviar para o GitHub:** 

bash

git push origin main    # Envia para a sua ramificação principal

Use o código com cuidado.
